# Farseer

Farseer는 사람 대신 웹사이트를 탐색하고, 비교나 의사결정에 필요한 자료를 구조화해서 수집하는 Playwright 기반 웹 조사 프로젝트다.

브라우저를 직접 열어 페이지를 살펴보는 단계부터 DOM 및 네트워크 요청 조사, 반복 가능한 데이터 수집까지 한 작업공간에서 수행한다. 사이트별 조사 내용과 진행 상황은 [PROJECTS.md](./PROJECTS.md)에 기록한다.

## 현재 상태

현재는 쿠쿠 밥솥 및 다나와 ATX 케이스 수집기와 시월모바일의 인증 후 사용량 조회 기능이 들어 있다. 공통 수집 프레임워크를 미리 만들기보다는 실제 조사 사례가 쌓일 때 재사용되는 부분만 분리할 예정이다.

## 구성

- `src/browse.ts`: 조사 대상 페이지를 실제 브라우저로 연다.
- `src/inspect.ts`: DOM 선택자와 상품 API를 진단한다.
- `src/scrape.ts`: 쿠쿠 밥솥 목록의 모든 더보기 페이지를 순회해 데이터를 수집한다.
- `src/scrape-danawa-atx-cases.ts`: 다나와 케이스 목록에서 ATX 지원 모델과 외형 크기를 수집한다.
- `src/siwol.ts`: 시월모바일 SMS 로그인 상태를 저장하고 headless 브라우저로 사용량을 수집한다.
- `data/`: 조사 결과를 저장한다.
- `PROJECTS.md`: 조사별 목표, 범위, 발견 사항과 다음 작업을 기록한다.

## 시작하기

요구 사항은 Node.js 24 이상이다.

```bash
npm install
npx playwright install chromium
```

## 명령

브라우저에서 조사 대상 페이지 열기:

```bash
npm run browse
```

현재 페이지의 DOM과 네트워크 요청 진단:

```bash
npm run inspect
```

쿠쿠 밥솥 전체 목록 수집:

```bash
npm run scrape
```

다나와 ATX 케이스 수집:

```bash
npm run scrape:danawa-atx
```

TypeScript 검사:

```bash
npx tsc --noEmit
```

## 시월모바일 사용량 조회

프로젝트 루트에서 실행한다. 최초 로그인 또는 서버 세션 만료 시:

```bash
npm run login:siwol
```

열린 브라우저에서 **가입자 인증**을 선택하고 직접 SMS 인증을 완료한다. 마이페이지의 `사용량 조회`가 표시되면 인증 상태를 저장하고 브라우저를 닫는다. 기존 인증이 유효하면 SMS 인증 없이 저장을 완료한다.

이후에는 브라우저 창을 띄우지 않고 조회한다:

```bash
npm run usage:siwol
```

- 출력 파일: `data/siwol-usage.json` (매 조회 시 덮어씀).
- 수집 내용: 수집시각, 사이트 조회시각, 사용기간, 요금제, 기본요금제·부가서비스별 사용량 및 제공량. 단위는 항목의 `label`에 사이트 표기 그대로 보존한다.
- 인증 상태: `.auth/siwol-state.json`. 브라우저 프로필: `.auth/siwol-profile/`.
- `JSESSIONID`는 세션 쿠키이므로 프로필만으로 종료 후 복원을 보장할 수 없다. 인증 상태 파일에서 명시적으로 복원한다.
- 인증이 없거나 만료되면 종료 코드 **2**와 재로그인 안내를 출력한다. SMS를 자동 요청하지 않으며 기존 결과 파일도 갱신하지 않는다. 소비자는 명령 성공 여부와 수집시각을 확인해야 한다.
- 인증 저장은 서버의 세션 만료를 연장하지 않는다. 유효기간은 아직 확인되지 않았다.
- `.auth/`와 `data/`는 Git에서 제외된다. 인증 파일은 평문 로그인 권한이므로 공유·업로드하지 말고 사용자 전용 로컬 폴더에 둔다.
- 같은 프로필을 사용하는 로그인·조회 명령을 동시에 실행하지 않는다.

## 조사 원칙

- 브라우저 동작을 먼저 확인하고 추측으로 선택자를 만들지 않는다.
- 위치 기반 Full XPath보다 안정적인 ID, 클래스, 속성 선택자를 우선한다.
- 화면 텍스트보다 구조화된 네트워크 응답이 있으면 이를 우선 수집한다.
- 원본 데이터와 후보 선정 기준을 분리해 나중에 판단 기준을 바꿀 수 있게 한다.
- 수집 시각과 출처를 결과에 남겨 가격처럼 변하는 정보를 구분한다.
